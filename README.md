 # SpendWise - Budget Tracker

## 1. Project Description
SpendWise is a web-based budget tracking application designed to help users manage their income, expenses, and available budget.

The application allows users to record expenses, organize spending information, calculate remaining balances, and monitor their financial activities.

## 2. Technologies Used

- HTML5 - Structure of the application.
- CSS3 - Styling and responsive design.
- JavaScript - Application functionality and calculations.
- Git and GitHub - Version control and project hosting.
- Netlify - Website deployment and hosting.

## 5. Deployment Process Summary
The SpendWise application was deployed using GitHub and Netlify.

First, all project files, including index.html, style.css, script.js, and README.md, were organized in one project folder.

Next, a public GitHub repository was created, and the project files were uploaded using Git.

Netlify was then connected to the GitHub repository. The main branch was selected, and the project was deployed as a static website.

After deployment, the generated Netlify URL was used to access the application online.

Automatic deployment was also tested by making an update to the project, committing the changes, and pushing them to GitHub. Netlify automatically detected the changes and published the updated website.

## 6. Challenges Encountered During Deployment
Some challenges encountered during deployment included:

- Configuring the GitHub repository correctly.
- Connecting GitHub to Netlify.
- Ensuring that all project files were included.
- Checking that CSS and JavaScript files loaded correctly.
- Verifying that automatic deployment worked successfully.

These challenges were addressed through testing and checking the deployment settings.
